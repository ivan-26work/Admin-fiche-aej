Guide d'utilisation

1. Connexion

Pour accéder à l'interface d'administration :

  • Saisissez votre email et votre mot de passe
  • Entrez le code secret : ipote233@
  • Cliquez sur "Se connecter"

⚠️ Le code secret est unique et confidentiel.

2. Tableau de bord

Le tableau de bord est organisé en deux colonnes :

  • Colonne gauche (30%) : Recherche, catégories, statistiques, accès rapide
  • Colonne droite (70%) : Filtres par date, grille des fichiers

Fonctionnalités :

  • 🔍 Recherche : filtre les fichiers par nom ou matricule
  • 📁 Catégories : cochez pour filtrer par catégorie
  • 📅 Filtres dates : cliquez sur une date pour voir les fichiers de ce jour
  • 📥 Téléchargement : cliquez sur l'icône de téléchargement
  • 🗑️ Suppression : cliquez sur la corbeille (confirmation requise)
  • 👁️ Aperçu : cliquez sur une carte pour visualiser le PDF

3. Upload de fichiers

Format obligatoire :

[Matricule] [Lettre] [Nom] [Désignation].pdf

Exemple :

19167122 F IPOTE fiche.pdf

Règles :

  • Matricule : 8 chiffres
  • Lettre : 1 majuscule (A-Z)
  • Nom : au moins 2 lettres (maj/min acceptées)
  • Désignation : texte libre (ex: fiche, attestation, diplome)

📌 Si le matricule existe déjà, l'ancien fichier sera automatiquement remplacé.

4. Gestion des catégories

  • Créer une catégorie : cliquez sur le bouton à côté de "Catégories"
  • Filtrer : cochez/décochez les catégories dans la colonne gauche
  • Supprimer une catégorie : appui long sur la catégorie, puis confirmation

⚠️ Supprimer une catégorie supprime TOUS les fichiers associés !

5. Consultation des téléchargements

La page Vu.html permet de consulter l'historique des téléchargements des stagiaires :

  • Filtres par date
  • Recherche par nom, prénom ou matricule
  • Affichage des détails (téléphone, filière, date)
  • Actions WhatsApp et appel direct

6. Bonnes pratiques

  • 📄 Nommez les fichiers selon le format obligatoire
  • 🔍 Utilisez les filtres pour retrouver rapidement vos fichiers
  • 📁 Organisez par catégories (filières, types, périodes)
  • 🔄 Vérifiez les doublons avant upload
  • 📱 Testez sur mobile pour vérifier le responsive
